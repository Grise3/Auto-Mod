How it works

AutoMod V2 is a tool focused on one thing: stopping compromised accounts from damaging your server. It uses several methods to detect suspect behavior.

🛡️ Pattern Detection (Anti-Spam)

This module watches for users sending the exact same message across different channels in a short time. This is a common sign of a hijacked account or a basic bot.

If a user hits the limit you set, the bot will automatically apply the configured sanction (like a 24h timeout).

🪤 Trap Channels

Designate specific channels as "trap channels". These are highly effective for identifying compromised accounts. Any user (unless they have an immune role) who posts a message in a configured trap channel will be immediately sanctioned according to your settings.

This helps to quickly isolate and deal with malicious actors who often try to post spam or scams in any available channel.

🔗 Link Filtering (Anti-Link)

Hacked accounts often post server invites to spread further. This module scans messages for Discord invite links.

You can choose to block all invites, or only those that contain suspect keywords (like "nitro", "gift", or "free") often used in scams.

🖼️ Advanced Image Detection

To combat scams that use images to bypass text filters, AutoMod V2 employs an EfficientNet deep learning model. This model analyzes images to categorize their content and detect known malicious patterns.

⚙️ Commands

/config panel

Opens the interactive dashboard to manage status, sanctions, and immune roles/channels for all modules, including Trap Channels and Image Detection settings.

/config getcode

Generates a 15-character seed representing your current logic settings.

/config setcode

Applies a configuration instantly using a seed code from our online tool.

/stats

Shows how many times the bot has intervened on your server.
